    Không bắt buộc

    Không có API key vẫn học và tự đánh giá được. API key dùng trực tiếp trong trình duyệt cá nhân; không thể bảo mật tuyệt đối nếu website hoặc thiết bị bị xâm nhập.

    Mặc định key chỉ giữ trong phiên trình duyệt. Dù lưu cách nào, key vẫn có thể nhìn thấy trong DevTools/network của chính thiết bị.
